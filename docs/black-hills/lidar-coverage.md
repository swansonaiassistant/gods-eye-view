# Black Hills 3DEP published point-cloud work units

The **BLACK HILLS LiDAR** panel queries the [USGS 3DEP Elevation Index, Lidar Point Cloud query layer](https://index.nationalmap.gov/arcgis/rest/services/3DEPElevationIndex/MapServer/24) when the user selects **SHOW FOOTPRINTS**. It draws the returned published work-unit polygons on the Cesium globe and lists work-unit/project names, USGS quality level, collection start/end, publication date, and outbound USGS source and metadata links. **REFRESH USGS** repeats the query. A failed refresh retains the previous data with a stale warning; an initial failure shows unavailable. No point clouds, DEMs, imagery, or historical reconstructions are downloaded or stored.

The query envelope `[-105.0, 43.35, -102.65, 45.05]` spans Black Hills and surrounding South Dakota/Wyoming terrain. It is a *research search box*, not an authoritative Black Hills boundary. A work unit that intersects it can extend outside it. Polygons may overlap or include areas without usable ground returns, and USGS publication dates differ from acquisition dates. No percentage coverage or missing-area claim is derived. The panel distinguishes published **LiDAR Point Cloud** work units from other 3DEP DEM products; it does not render point clouds or replace the current terrain stack. For download/quality decisions, follow each USGS project metadata link or [3DEP LidarExplorer](https://apps.nationalmap.gov/lidar-explorer/).

Source: USGS Work Unit Extent Spatial Metadata (WESM), surfaced by the 3DEP Elevation Index MapServer. The [USGS WESM dictionary](https://www.usgs.gov/ngp-standards-and-specifications/wesm-data-dictionary) describes published work units, quality levels, and collection dates. [USGS states all 3DEP products are public domain and available without use restrictions](https://www.usgs.gov/3d-elevation-program/). The app fetches the current index at runtime and credits USGS in the panel; it bundles no third-party data.

## Verification

On 2026-11-19, an unauthenticated browser-compatible query returned HTTP 200 with `Access-Control-Allow-Origin: *` and 12 published LPC work-unit records intersecting the study box. The ArcGIS query supports `returnIdsOnly` followed by bounded `objectIds` GeoJSON geometry requests. This is a point-in-time response, not a fixed expected count or guarantee of future availability.
